# The Code of Hammurabi in Akoma Ntoso

The Code of Hammurabi, from about 1754 BC, in L. W. King's English translation, in Akoma Ntoso XML, with a CSS stylesheet that renders it in the manner of a basalt stele. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `code-of-hammurabi.xml` | The Akoma Ntoso document |
| `code-of-hammurabi.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Document type:** The Code is an `<act name="code">`. The prologue is a `<container>` in `<preamble>`, the 247 numbered laws are `<section>` elements in `<body>`, and the epilogue is a `<container>` in `<conclusions>`.
- **Numbering:** The numbers are the conventional modern ones, as the source gives them. The stele itself has no numbers. Eids follow the numbers, so `sec_196` is law 196.
- **Gaps:** Laws 66 to 99 are in the part of the stele that is missing. The source's note on this is in `<hcontainer name="lacuna">`. Law 13 is also absent from the source. Ellipses in the source, where words are unknown, are marked with `<omissis>`.
- **Glosses:** The source adds "An eye for an eye" to law 196 and "A tooth for a tooth" to law 200. Neither is in the laws themselves. Both are kept in `<span class="gloss">`.
- **Highlights:** Laws 196, 197 and 200 are in `<span class="landmark">`. The highlighting is editorial.
- **Line breaks:** The source breaks some epilogue paragraphs in mid-sentence. Those are rejoined. The text is otherwise verbatim, including the straight quotation marks and the source's `. . ..` in law 274.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither.
- **Dates:** `-1754-01-01` and `1915-01-01` are nominal dates, used because the schema needs a full date. The date of the Code is approximate.
- **Jurisdiction:** The URIs use `babylon`.

## Sources

Text: L. W. King's translation, from the [Avalon Project](https://avalon.law.yale.edu/ancient/hamframe.asp) at Yale Law School. This is an English translation. The Akkadian original is not included.

King's translation is more than a century old and reflects its time, and modern translations differ in places. The cuneiform in the heading spells Hammurabi's name and is decorative.

## Fonts

The stylesheet embeds Marcellus, Spectral and a subset of Noto Sans Cuneiform, all licensed under the [SIL Open Font License](https://openfontlicense.org/). The stone is a CSS texture. The rendering does not reproduce the stele.
